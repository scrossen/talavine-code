# Contributing

Bug reports, documentation improvements, tests, and focused fixes are welcome.
For substantial changes, discuss the problem and proposed approach in an issue
before implementation. Maintainers decide which changes to accept.

Include the operating system, SDK version, reproduction steps, expected behavior,
and actual behavior. Use a synthetic repository and redact logs. Never attach
API keys, password exports, personal messages, private repositories, or live profiles.

Build the CLI solution and run the affected test projects using the README commands.
Keep reusable behavior in its owning SwarmCore library; hosts own persistence,
credentials, policy adapters, and UI. Do not add dependencies on private products.
Keep provider support structural rather than adding customer-specific branches.

Contributions must be yours to submit. Unless explicitly agreed otherwise,
contributions to Talavine-owned code are under this repository's MIT license.
Retain upstream attribution and license notices for third-party material.

Public discussions are for reproducible bugs and development. Do not assume a
response deadline or ongoing support obligation. Private integrations and support
arrangements can be discussed through the Talavine website.
